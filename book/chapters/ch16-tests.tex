\label{ch:tests}

\section{One suite}

The architectural tests are a single directory. Each test names the narrowest profile that must run it. A wider profile runs it too. A narrower profile does not assemble it, or assembles it and expects an illegal-instruction trap, and the expected trap is itself a test.

\section{The fill}

\begin{lstlisting}
// n bytes at dst become the byte fill
// assembled once, linked into every image
void fill8(uint8_t *dst, uint8_t fill, size_t n);
\end{lstlisting}

The reference is a scalar loop in the testbench, not in the hart. The hart's result is read back through the bus with the vector unit idle, so that a buggy load unit cannot hide a buggy store unit by reading its own write buffer. Compare all \texttt{n} bytes, including when \texttt{n} is one more than a multiple of VLMAX. That last iteration is the one that sets \texttt{vl} to a remainder.

\section{Illegal SEW}

On each image, execute \texttt{vsetvli} with a SEW the profile forbids: 16 on SVM-8, 32 on SVM-16, 64 on Zve32f, 128 on BX-128, 512 on BX-512. Then execute \texttt{vadd.vv}. The add must trap. \texttt{vl} must be unchanged from the previous legal configuration, or zero if there was none, according to the rule you wrote down for \texttt{vill}. The test checks the CSR, not only the trap, because a trap with a silently updated \texttt{vl} will break the next legal loop.

\section{RV128 images}

\texttt{quad}, \texttt{add128}, \texttt{addd16}, \texttt{zext64}, and \texttt{sh64} run on an RV128 hart. They are integer parcels, and they are outside the travelling vector suite. On BX-128, XLEN is 64, so \texttt{lq} and a shift immediate of 64 are illegal. That trap is the check that the VLEN pin and the integer base stayed apart.

\section{Xsvm tests are separate}

Tests that emit the custom matrix or cross-product opcode live in another directory and run only on elaborations with \texttt{xsvm} true. They are not part of the travelling suite. A clean BX-16 image must fail those tests by trapping, and the travelling suite must still pass.

\section{Random parcels}

After the directed tests, a small generator that emits legal OP-V for the profile, runs the parcel on the hart and on a scalar reference model, and compares the destination register, will find the lane-enable bugs that VLMAX and \texttt{vl}=1 do not catch. Bound it. A few thousand parcels per profile are enough for a teaching design. Record the seed.
